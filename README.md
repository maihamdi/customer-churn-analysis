# Databel Customer Churn Analysis

## Project Overview

This project analyzes customer churn data for Databel using Microsoft Excel.

The goal of the analysis is to understand customer churn patterns and identify the main factors associated with customer attrition.

## Tools & Skills

- Microsoft Excel
- Data Cleaning
- Excel Functions
- PivotTables
- PivotCharts
- Data Visualization
- Churn Rate Analysis
- Dashboard Creation

## Analysis

The project explores customer churn across several dimensions, including:

- Churn Reasons
- Churn Categories
- Demographics
- Age Groups
- Account Length
- Contract Type
- International Plan
- State
- Data Usage

## Dashboard

An Excel dashboard was created to summarize key customer churn metrics and provide an overview of the main patterns found in the data.

## Key Insights

The analysis highlighted differences in churn rates across customer groups, contract types, international plans, and other customer characteristics.
